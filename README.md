# dsh-tavern-comfy

**给 DSH Tavern 用的本地 ComfyUI 场景生图插件**

正文写到哪，图就配到哪 —— 用你自己显卡上的 ComfyUI 画，不花钱、不限量、风格自己定。

```text
你只管写故事          ─────────────────────────────────────────────┐
                                                                    │
  ①  这一轮正文写完                                                 │
  ②  后台另起一次模型调用：「配几张？插在哪句后面？画什么？」        │
  ③  每解析出一张完整画面就提交 ComfyUI，继续规划后面的画面          │
  ④  Tavern 把图按锚点插进正文，并跟这版正文绑定                     │
                                                                    │
◄───────────────────────────────────────────────────────────────────┘
   回退正文版本，图自动收起；切回来，图又出现
```

> **v1.1.0** — 全面改走 **Tavern 官方插件接口**（`tavern.*` / `tavernUi.*`），不再给 Tavern 打任何补丁。
> 使用公开接口，宿主更新不会冲掉插件补丁；官方接口出现不兼容变化时仍需适配。

## 三十秒看懂

只要记住三件事：

| | |
|---|---|
| 🖼 **图长在正文里** | 插在**它描述的那句话后面**，按剧情分散，不堆在开头或结尾 |
| 🎛 **前台不用管图** | 前台模型专心写故事；配几张、画什么，交给后台一次单独的规划调用 |
| 🔌 **不打补丁** | 全部走 Tavern 公开接口，Tavern 更新不会再把图或按钮冲掉 |

再做四步配置就能用：**连 ComfyUI → 导工作流 → 选规划模型 → 开自动配图**。往下就有。

## 三分钟跑起来

**前置**：你已经在用 DSH Desktop，并且 ComfyUI 能正常出图。

### 第 1 步 · 装插件

```bash
cd ~/.dsh/profile-data/tavern/data/tools
git clone https://github.com/weixinlll/dsh-tavern-comfy.git
```

> Windows 上是 `%USERPROFILE%\.dsh\profile-data\tavern\data\tools`
> 不想用 git 就手动下载，把整个文件夹丢进上面那个 `tools` 目录里。

**然后完整重启 DSH Desktop** —— 关掉整个程序再打开，**刷新页面不够**。

### 第 2 步 · 连上 ComfyUI

重启后打开 **设置 → 本地生图**，第一个标签页「**生图规划**」最上面就是「生图后端」：

```
API 根地址   [http://127.0.0.1:8188        ]
服务鉴权     [无需鉴权                    ▾]

[ 测试连接与鉴权 ]
```

点「**测试连接与鉴权**」。看到绿色的

```
● 在线  0.38.2   RTX 4090   24GB   ✓ 28ms
```

就通了。设过密码的话，在这里选 Bearer Token 或 Basic 并填上。

### 第 3 步 · 导入一个工作流

切到「**画风**」标签页 → **📥 导入工作流**。

**必须是 ComfyUI 的「API 格式」导出**：

- ComfyUI 右上角菜单 → `Workflow → Export (API)`
- 或先在设置里打开 `Enable Dev mode Options`，菜单里就会出现 `Save (API Format)`

导入后会立刻告诉你识别到了什么：

```
✓ 已导入《my-flow》节点 12 个，识别到：
  正面 1 / 负面 1 / 尺寸 1 / 步数 1 / 底模 1 / LoRA 2
```

识别错了就展开它，点「**✏️ 编辑 / LoRA**」当场改。最后**设为默认**。

### 第 4 步 · 选规划模型

回到「生图规划」，往下有两个下拉：

```
规划模型  [渠道 ▾] [模型名 ▾]          不选 = 跟随 Tavern 后台模型
看图模型  [渠道 ▾] [模型名（👁）▾]     只列支持看图的
```

- **规划模型**：把剧情翻译成绘图提示词的那个模型。**不选就会跟随 Tavern 的后台模型**，但建议自己指定一个稳定的。
- **看图模型**：只在「设计角色」读参考图时用到，**必须支持视觉**（列表里带 👁 的）。

> **想画 NSFW**：别用会拒绝的官方模型，换成你自己的渠道模型。规划模型拒绝输出了，这一轮就没有图。

### 完事，回去正常聊天

默认**不需要手动点任何按钮**。写完一轮正文，图会自己配好、插进对应段落。

**想确认真的通了**：随便聊一轮，正文下方应该出现「生成中…」的占位，几十秒后变成图。

## 插件更新

在本地生图面板打开 **插件更新**，先点 **检查更新**，有可用更新时再点 **更新插件**。这里显示当前加载的版本和检查到的远端版本；进入页面不会自动检查或安装。完成后请完整关闭并重启 DSH Desktop，页面刷新不能重新加载宿主代码。

自动更新适用于从本项目 Git 仓库安装、处于 `master` 分支的插件。更新只对插件自身目录执行向前更新，不会清空目录或覆盖本地代码改动；配置、人物库、世界书和用户工作流保持原样。人物草稿未保存、本地代码有改动、提交分叉或远端改动涉及用户数据路径时，会停止安装并说明原因。手动下载的安装方式会显示项目链接，供手动更新。

这项功能使用插件自己的更新路由维护自身源码，**不是 Tavern 的官方包管理更新接口**。DSH 当前没有供普通插件调用的自更新 API，参见[官方插件管理界面的限制说明](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-plugin-manager/README.md#known-limitations-and-deferred-work)。本插件的 Tavern 生图与消息展示对接仍使用下述官方接口，不改宿主源码，也不更新 Tavern 主程序。

## 为什么改用官方接口

早期版本靠**给 Tavern 客户端源码打补丁**才能把图塞进正文。结果是 Tavern 一更新、补丁被还原，插件就瞎了 —— 典型症状是「正文里的图不显示」和「🎨 生图按钮消失」**同时**发生。

现在整条链路都是正门：

| 环节 | 走的接口 |
|---|---|
| 什么时候配图 | `tavern.onTurnSettled` —— 每轮结算后服务端通知一次（不再是前端"渲染时猜"） |
| 图怎么进正文 | `tavern.attach` / `tavern.update` —— 按 `anchor` 锚定，与正文版本 `textVersion` 绑定 |
| 图存在哪 | DSH `attachments.saveImage` —— 不再自建取图路由 |
| 手动生图按钮 | `tavernUi.registerMessageAction` |
| 正文里的 `image###` 标记 | `tavernUi.registerTextMarker` |
| 图怎么显示、多大、右键菜单 | `tavernUi.registerMediaRenderer`（自定义媒体类型，显示归自己管） |
| 生图规则注入 | `tavern.promptSection` |
| 当前玩的是哪张卡 | `getTurn` / `onTurnSettled` 回调里的 `card` 字段 —— 不去翻会话目录 |
| 卡的设定与世界书 | `tavern.getCardContext` —— 不自己解析卡片文件 |
| 默认后台模型 | `tavern.backgroundModel` —— 不读 `tavern-settings.json` |

**插件不写别人的数据。** 以前它会在规划前往「你正在玩的那张卡」的文件里塞一条显示正则，现在整块删掉了 —— 直接改用户的卡片会绕过 Tavern 的卡片管理与备份，而且图早就不靠那条正则显示。

适配层集中在一个文件：`lib/tavern-bridge.js`。

**老实说的边界**：如果 Tavern 将来升级官方接口本身（版本号不兼容），仍然需要适配一次。但接口带 `apiVersion`，那种事不会静默发生 —— 你会在日志里看到版本不符，而不是某天发现图不见了。

## 日常怎么用

**① 自动配图（默认）**

配好之后什么都不用做。一轮正文写完 → 后台规划 → 出图 → 插图。

规划模型输出一张完整的 `<image>` 后，就会把这张图提交到 ComfyUI，后续画面的规划与已提交的出图重叠进行。每张完成的图片独立显示，不再等待前面的图片。ComfyUI 仍使用自身的队列，插件不会为了提速强行增加显卡并发。

**启动时机**：当前 Tavern 公开的 `onTurnSettled` 在后台结算结束后触发，没有提供正文生成中的通知。因此这版优化减少的是规划和出图之间的等待，不能让插件提前启动或加速 Tavern 自己的结算。

**② 手动补一轮**

点消息下方那颗「**🎨 生图**」。走的是同一条链路，**跟自动开关无关，随时能点**。

**③ 摆弄已经出来的图**

| 操作 | 效果 |
|---|---|
| **点一下图片** | 打开全屏查看器 |
| **右键 / 长按图片** | 改提示词、让模型重写、重画 |
| **查看器两侧的大 ‹ ›** 或 **键盘 ← →** | 翻**整场对话里的插图** |
| **滚轮** | 缩放（0.2x ~ 8x） |
| **按住拖动** | 放大以后平移 |
| **图片下方「重画版本 ◀ 2 / 3 ▶」** | 翻**这张图自己的重画历史** |

查看器标题栏会把两件事一起写清：

```
[褪白格子床上的交合]   第 3 / 18 张   （这张有 2 个重画版本）
```

**④ 重画**

右键图片 → 改正向 / 反向提示词 → 点「**🎨 用这段重画**」。

同一位置**直接换成新图**，旧版留在「重画版本」里，可以来回对比。不满意就再改。

> 重画历史存在浏览器本地，**只有用「🎨 用这段重画」产生的新版本才会进版本链**。

## 两个开关，别搞混

插件里有**两条不同的配图链路**，开关不在同一个地方：

| 开关 | 在哪 | 默认 | 它管什么 |
|---|---|---|---|
| **每轮自动规划配图（前台只写正文）** | 设置 → 本地生图 → **生图规划** | **开** | 正文写完后，**后台**自动规划并插图。前台模型完全不管图 |
| **自动生图** / **生图数量** | **控制台**（右下角浮动按钮） | 关 | 让**前台模型自己**在正文里写 `image###英文Tag###` 标记，再渲染成图 |

**建议只用第一个。** 前台专心写故事、配图交给后台，位置和画质都更可控。

第二个是备用通道：给不想多花一次规划调用的场景，但要求你的前台模型愿意写标记。

同一页往下还有两个值得调的：

- **一轮几张**（1 ~ 8，**建议 2 ~ 3**）：本地出图一张几十秒，设太多一轮要等很久
- **人物块**：
  - `自动（画面露才带露出版本）` —— 默认，按画面判断要不要带 NSFW 分块
  - `只带常规版本` —— 永远只用穿衣服的分块
  - `全都带上` —— 全塞进提示词，容易穿错

## 界面详解

设置面板一共五个标签页。下面按你可能想改的东西组织。

### 生图规划

| 项目 | 说明 |
|---|---|
| **生图后端** | ComfyUI 地址与鉴权、测试连接 |
| **每轮自动规划配图** | 上面那个主开关 |
| **一轮几张** | 一轮正文配几张图，1 ~ 8 |
| **人物块** | 人物库里 SFW / NSFW 分块的使用策略 |
| **规划模型** | 翻译剧情的人；可指定渠道 + 推理等级 |
| **看图模型** | 只看图时用，必须支持视觉 |
| **世界书（N 条，已启用 M 条）** | 当前有哪几条规则会发给规划模型，可一键跳去编辑 |

### 画风

两件事都在这儿。

**工作流** —— 导入的必须是 **API 格式**。导入后插件自动识别：

| 识别项 | 靠什么判断 |
|---|---|
| 正 / 负面提示词 | 看**谁连到采样器**的 `positive` / `negative` |
| 尺寸 / 步数 / CFG | 采样器和 latent 节点的对应输入 |
| 底模 | CheckpointLoader / UNETLoader |
| LoRA | 所有 `LoraLoader` 节点 |
| 输出节点 | SaveImage / PreviewImage |

**多张工作流**可以都导入，用「设为默认」切换；想锁住就勾「锁定」。

**LoRA**：展开工作流能看到所有 LoRA 节点 —— 勾选启用（**停用 = 权重设 0，不删节点，所以连线不会坏**）、改权重、从已安装列表里换。

**画风预设** —— 每套 = 画师串 + 它自带的负面词，还能选「放在提示词最前还是最后」。多套之间一键切换，适合「日常 / 暗调 / 明亮」这种分场景使用。

### 人物库

**这个建了，同一角色才不会换脸。**

每个角色分块存外貌：

```
角色特征
五官（正面） / 五官（背面）
上半身 SFW / 上半身 SFW 背面
下半身 SFW / 下半身 SFW 背面
上半身 NSFW / 上半身 NSFW 背面
下半身 NSFW / 下半身 NSFW 背面
+ 常穿服装（可多套，标一套为「常穿」）
```

填了名字 + 五官 + 体态的角色，会作为「**可用角色清单**」交给规划模型。正文里出现这个名字时，相应内容自动补齐 —— 这就是不换脸的原因。

生成时用宏调用：

```
${"name":"xiao yu", "angle":"from front", "upperBody":"sfw", "lowerBody":"sfw"}$
${"name":"湿透的灰色短打", "upperBody":"visible", "lowerBody":"visible"}$
```

- `angle`：`from front` / `from above` / `from below` / `from side` / `from behind`
- `upperBody` / `lowerBody`：`sfw`（有衣物）/ `nsfw`（裸露）/ `hidden`（不在画面里）

**不建也能用** —— 模型会自己写外貌 Tag，只是同一角色前后不一致的概率大一些。

**懒人路线**：**人物库 → 喂一张参考图 → 让模型设计**。模型按「角色与服装设计规范」产出分块外貌，你确认后直接入库。

> ⚠️ 人物库有**防清空闸门**：保存时如果会把已有角色清掉，插件会拒绝并提示，不会默默清库。

人物库采用**搜索 + 当前角色下拉选择**，一次只显示所选角色的编辑内容。可按中文名或英文触发名搜索，选择框按中文名排序，人物库的存储顺序不变。切换角色时保留各自草稿；「收起编辑」只折叠当前角色，上方选择框始终保留。

选择框旁集中放置新增、复制、识图、设计和保存操作。**复制当前角色**会保留外貌、服装和绑定，并生成新的角色与服装编号，修改副本不会影响原角色。新建、复制或设计完成后会自动选中新角色。

需要同时修改多位角色时，展开**批量编辑**中的紧凑选择区。「全选当前筛选」只加入当前搜索结果；切换搜索不会丢失之前选中的角色。可以批量覆盖或追加外貌字段、说明等内容，也可以批量启用、禁用或设置卡片绑定。批量修改先留在编辑区，检查后点**保存人物库**写入；角色设计和改进生成的结果会自动保存。

角色预设选择方式参考了 [st-chatu8 的角色预设界面](https://github.com/damoshen123/st-chatu8/blob/50f0d200caea17c448e80432f1b54d65ed8ce9cd/html/settings/character.html)。Tavern 对接仍使用本插件原有的官方接口。

后台刷新及角色设计返回时，会合并到最新人物库，保留其他角色正在编辑的内容。图片说明由 Tavern 统一显示，只保留一处。

### 世界书

「世界书」标签页 = **画图规则**。启用的条目拼成一段规则，发给**规划模型**。

- **📥 导入世界书** —— 可以直接吃 SillyTavern 的世界书 JSON；也能把 JSON 或纯文本粘在下面（**纯文本按空行切条**）
- **逐条开关 + 改内容** —— 只有 `enabled` 是开关
- 条目里的 `{@setvar::...@}`、`{{...}}`、`<system_override>` 这类**给别的引擎看的语法会被自动剥掉**，不会污染规划模型

**首次运行自带 8 条「通用生图规则」**，可以直接用。插件只会在这份文件**不存在**时生成它，之后**永不覆盖**你改过的内容。

**输出契约**（想自己写规则，规划模型要按这个吐）：

```xml
<image>
<regex>从正文里原样复制的一句话</regex>
<title_styled>5~15 字中文标题</title_styled>
<Tag_think>这张画的画面概括</Tag_think>
<size>竖图</size>
<prompts>这里写提示词</prompts>
</image>
```

- **`<regex>`** 是**挂载位置**：插件拿它去正文里找，插在那句话之后。**必须逐字存在**，找不到这张图就掉到末尾。
- **`<prompts>`** 是**提示词**：缺这个，整块会被丢弃。

仓库里那份 `世界书-通用生图规则.json` / `.txt` 就是默认规则的原文，`.txt` 是纯文本版，方便复制给别人。

## 出问题了先看这里

快速定位表 —— **哪个症状，先查哪一行**：

| 症状 | 大概率是 |
|---|---|
| 一轮聊完没有图，占位也不出现 | 「每轮自动规划配图」没开，或者规划模型没选 |
| 有占位，但一直是「生成中…」 | ComfyUI 那边有问题（工作流没设为默认 / ComfyUI 关了） |
| 规划跑完了，但一张都没出来 | 规划模型没按 XML 格式输出，换个模型试 |
| 图出来了，但全堆在正文末尾 | 规则里 `<regex>` 写的那句话在正文里找不着 |
| 图一直在「正在取回…」 | 文件比作业标记晚落盘，插件会自己重试；超过 30 秒点「重试」 |
| 某个角色每张图长得不一样 | 人物库没建，或正文里没出现库里登记的名字 |

下面是详细的。

**Q：生成了但正文里没图**

按顺序查：

1. **生图规划** 里「每轮自动规划配图」有没有开
2. **规划模型** 选了吗（或确认能跟随 Tavern 后台模型）
3. **画风** 里有没有「正在使用」的工作流
4. 设置页顶部的 ComfyUI 状态是不是绿的

**Q：图片掉到正文末尾了**

**规则里 `<regex>` 写的句子在正文里找不着。** 对照生成的提示词和原文 —— 一般是模型改写原文了（多字、少字、换了标点）。把 `<regex>` 截短、截准，情况会好很多。

**Q：规划完了但一张图都没有**

规划模型没按格式输出。**换个模型试试** —— 有些模型不认 XML 标签，尤其是小模型和推理被压得很低的配置。

**Q：图一直显示「正在取回」**

出图文件落盘比作业标记完成晚几十秒。插件会自动重试（1.5 秒一次，最多 20 次 ≈ 30 秒），**先等一会儿**。真超过 30 秒才点「重试」。

**Q：ComfyUI 连不上**

- ComfyUI 开着吗？（浏览器能打开 `http://127.0.0.1:8188` 吗）
- 地址和端口填对了吗？（默认 8188）
- 设了密码的话，「服务鉴权」要选对并填上

**Q：出图很慢**

本地出图就这样，一张 768×1024 大概 20 ~ 60 秒（看显卡）。**把「一轮几张」降到 2 ~ 3**。

**Q：改了 `worldbook.json` 文件但插件没变**

插件缓存了世界书。**别直接改文件** —— 用「世界书」标签页改，它会自己刷新。

**Q：改了代码没反应**

- **`client.js`（前端）**：刷新页面就够（会自动热重载）
- **`lib/` 里的任何东西（宿主侧）**：必须**完整重启 DSH**，F5 不行

**Q：怎么确认插件真的活着**

浏览器开 `http://127.0.0.1:43120/plugins/dsh-tavern-comfy/state`，`config.tavernBridge` 里应该有：

```json
{ "installed": true, "exports": ["available", "attachTurn", "dispose"] }
```

## 数据与隐私

**下面这些东西是你自己的，不进公开仓库**（都在 `.gitignore` 里）：

```
config.json        你的 ComfyUI 地址、鉴权、工作流绑定
worldbook.json     你的生图规则（人物库 / 服装库 / 体位规则都在这里）
definitions.json   你的人物库、服装库
jobs-store.json    出图历史
plans-store.json   插图计划
backups/  cache/   备份与图片缓存
workflows/*.json   你自己的工作流
```

仓库里只有**代码**和**一份通用规则种子**。别人 clone 下去拿到的是干净的空壳，第一次启动会自己生成默认世界书。

**想把配置搬给别人？** 别拷贝整个文件夹 —— 用「世界书」标签页的**导出**功能，它只导出规则，不含你的地址和密钥。
