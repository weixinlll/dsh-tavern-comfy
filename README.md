# dsh-tavern-comfy

**DSH Tavern 的本地 ComfyUI 场景生图插件**

把正文里的关键时刻变成图，内联插在段落之间 —— 用你自己电脑上的 ComfyUI 画，不花钱、不限量、风格自己定。

---

## 它能做什么

| 功能 | 说明 |
|---|---|
| **每轮自动配图** | 后台按剧情规划配几张、插在哪、画什么，前台只管写正文 |
| **图片内联插入** | 图插在它描述的那段正文**后面**，不是全堆在末尾 |
| **本地 ComfyUI** | 连你本机的 ComfyUI（默认 `127.0.0.1:8188`），用你自己的模型和工作流 |
| **工作流库** | 从 ComfyUI 导入 API 格式 JSON，插件自动认出正负面/尺寸/步数/底模/LoRA |
| **LoRA 管理** | 勾选启用、改权重、从已安装列表里选 |
| **画风预设** | 多套风格（画师串 + 专属负面词），一键切换 |
| **人物库** | 存角色的外貌分块（正面/背面、SFW/NSFW），生成时用 `${...}$` 宏调用，保证同一角色每张图长得一样 |
| **生图世界书** | 决定"怎么把剧情翻译成提示词"，可导入/逐条编辑 |
| **设计角色** | 给一张参考图，让模型看图设计出可入库的角色 |
| **历史图库** | 看历史、批量删、右键改提示词重画、上一张/下一张翻看 |
| **重画** | 一条消息里的图不满意，改提示词重画，版本可回溯 |

## 安装

**前置**：你已经在用 **DSH Desktop**，并且 **ComfyUI 能正常出图**。

### 方式一：从 GitHub 装（推荐）

## 首次配置

重启后打开 **设置 → 本地生图**，按顺序做四件事：

### 1. 填 ComfyUI 地址

**生图规划** 标签页最上面是「**生图后端**」：

```
API 根地址   [http://127.0.0.1:8188        ]
服务鉴权     [无需鉴权                    ▾]

[测试连接与鉴权]
```

点「**测试连接与鉴权**」，看到绿色的 `● 在线 0.38.2　RTX 4090　24GB　✓ 28ms` 就对了。

> 如果 ComfyUI 设了密码，在这里选 Bearer Token 或 Basic 并填上。

### 2. 导入一个工作流

**画风 → 工作流 → 📥 导入工作流**

**必须用 ComfyUI 的「API 格式」导出**：

- ComfyUI 右上角菜单 → `Workflow → Export (API)`
- 或先在设置里打开 `Enable Dev mode Options`，菜单里会出现 `Save (API Format)`

导入后会告诉你识别到了什么：

```
✓ 已导入《my-flow》节点 12 个，识别到：
  正面 1 / 负面 1 / 尺寸 1 / 步数 1 / 底模 1 / LoRA 2
```

**然后点它右边的「⚡ 试跑一张」** —— 能出图就说明通了。最后点「**设为默认**」。

### 3. 选规划模型

同一个标签页往下，「**规划模型**」和「**看图模型**」都是下拉框：

```
规划模型  [DeepSeek 官方 ▾]  [DeepSeek-V41-Flash ▾]
推理等级  [High ▾]

看图模型  [DeepSeek 官方 ▾]  [xxx（👁）▾]     ← 只列支持看图的
```

- **规划模型**：负责把剧情翻译成绘图提示词。**不选就跟随 Tavern 的后台模型。**
- **看图模型**：设计角色读参考图时用，**必须支持视觉**（带 👁 标记的）

> **想画 NSFW**：别用会拒绝的官方模型，选你自己的渠道模型。

### 4. 检查世界书

**世界书** 标签页应该有 **8 条「通用生图规则」**，都是勾选状态。

这些条目决定"**怎么把剧情翻译成提示词**"。默认那套已经调好，可以直接用；也可以自己导入别的、逐条开改。

## 怎么用

配好之后，**回聊天里正常对话就行**。

后台会：
1. 读一遍正文
2. 决定配几张图、插在哪几句后面、每张画什么
3. 翻译成英文提示词 → 交给 ComfyUI
4. 出图后插进正文

**图会插在它描述的那段话后面。** 想调整的话，一张图不满意 → **右键 → 改提示词重画**。

## 人物库（推荐建）

**人物库** 标签页里可以建角色。**每个角色分块存外貌**：

```
正面五官 / 背面五官
上半身 SFW / 上半身 SFW 背面
下半身 SFW / 下半身 SFW 背面
上半身 NSFW / 上半身 NSFW 背面
下半身 NSFW / 下半身 NSFW 背面
```

**为什么值得建**：生成时用宏调用（`${"name":"su qingyi", "angle":"from front", "upperBody":"sfw"}$`），插件会自动把外貌展开进提示词。**这样同一个角色每张图长得都一样**，不会这一张黑发下一张白发。

没建也能用 —— 模型会自己写外貌 Tag，只是稳定性差一点。

### 还可以让模型帮你建

**人物库 → 喂一张参考图 → 让模型看图设计**：

```
[选参考图]  [让模型设计]
```

模型会看图写出分块外貌，确认后写进人物库。

## 世界书（进阶）

默认的「通用生图规则」是这样的结构：

```
01 核心任务          每次回复都配图、分散插
02 输出格式          <image> 结构（照抄）
03 提示词写法        自然语言长句 + 句尾 Tag 锚定
04 人物库与服装库的调用  ${...}$ 宏格式
05 画面边界          只写看得见的
06 常用 Tag 参考     景别/角度/光线/姿势…
07 完整示例          一个带角色宏的完整例子
08 常见错误          检查清单
```

**关键契约**（如果你想自己写）：

```xml
<image>
<regex>从正文里原样复制的一句话</regex>
<title_styled>5~15 字中文标题</title_styled>
<Tag_think>这张画的画面概括</Tag_think>
<size>竖图</size>
<prompts>这里写提示词</prompts>
</image>
```

- **`<regex>`** 是**挂载位置** —— 插件拿它去正文里找，插在那句话之后。**必须逐字存在**，找不到就掉到末尾。
- **`<prompts>`** 是**提示词** —— 缺这个整块会被丢弃。

可以导入别人的世界书，只要它用这套字段。

## 工作流

**导入的必须是 API 格式**（不是普通导出）。导入后插件会**自动识别**：

| 识别项 | 靠什么 |
|---|---|
| 正/负面提示词 | 看**谁连到采样器**的 `positive`/`negative` |
| 尺寸 / 步数 / CFG | 采样器和 latent 节点的对应输入 |
| 底模 | CheckpointLoader / UNETLoader |
| LoRA | 所有 `LoraLoader` 节点 |
| 输出节点 | SaveImage / PreviewImage |

**识别错了可以改** —— 展开工作流，「💾 保存参数」那块直接改值。

**多张工作流**：可以都导入，用「**设为默认**」切换。想锁定就勾「锁定」。

**LoRA**：展开工作流能看到所有 LoRA 节点，勾选启用（停用 = 权重设 0，不删节点所以连线不会坏）、改权重、从已安装列表里换。

## 常见问题

**Q：生成了但正文里没图**

按顺序查：
1. **生图规划** 里「每轮自动规划配图」有没有开
2. **规划模型** 选了吗（或让它跟随 Tavern 后台模型）
3. **画风** 里有没有「正在用这张」的工作流
4. 看设置页顶部的 ComfyUI 状态是不是绿的

**Q：图片掉到正文末尾了**

**世界书里 `<regex>` 写的那句话在正文里找不着。** 去生成记录里看模型写的是什么，对照正文 —— 一般是它改写了原文（多字、少字、换了标点）。

**Q：规划跑完了但一张图都没有**

规划模型没按格式输出。**换个模型试试** —— 有些模型不认 XML 标签格式。用「规划模型」下拉换一个渠道模型。

**Q：ComfyUI 连不上**

- ComfyUI 开着吗？（浏览器能打开 `http://127.0.0.1:8188` 吗）
- 地址填对了吗？（默认端口 8188）
- 设了密码的话，「服务鉴权」要选对并填上

**Q：出图很慢**

本地出图就这样。一张 768×1024 大概 20~60 秒（看显卡）。**建议「一轮几张」设 2~3**，别设太多。

**Q：改了 `worldbook.json` 文件但插件没变**

插件缓存了世界书。**别直接改文件**，用「世界书」标签页改（它会自己刷新）。

**Q：`client.js` 改了没反应**

**DSH 在启动时加载前端，改了要完整重启 DSH**（关掉整个程序），F5 不够。

## 环境要求

- **DSH Desktop** `>=0.1.0-rc.8`
- **ComfyUI**（本地或局域网内可访问）
- 一个**能按格式输出的规划模型**（默认跟随 Tavern 后台模型）

## 目录结构

```
dsh-tavern-comfy/
├── package.json          插件清单
├── cordis.patch.yml      DSH 挂载配置
├── client.js             前端（设置面板 + 正文插图渲染）
├── console.html          独立控制台页（备用）
├── design-rules.md       设计角色的提示词
├── lib/
│   ├── index.js          宿主主体（路由、生成队列、世界书、工作流）
│   ├── planner.js        生图规划（调模型 → 解析 <image> → 出图）
│   └── prompts.js        自动生图规则（注入系统提示词）
├── workflows/            工作流（API 格式 JSON）
└── worldbook.json        默认世界书（通用生图规则）
```
