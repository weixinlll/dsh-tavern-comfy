# dsh-tavern-comfy

**DSH Tavern 的本地 ComfyUI 场景生图插件**

把正文里的关键时刻变成图 —— 用你自己电脑上的 ComfyUI 画，不花钱、不限量、风格自己定。图**内联插在它描述的那段正文后面**，不是堆在末尾。

> **1.1.0**：全面改走 **Tavern 官方插件接口**（`tavern.*` / `tavernUi.*`），不再需要给 Tavern 打补丁。
> **Tavern 以后怎么更新，这个插件都不会再坏。**

---

## 它能做什么

| 功能 | 说明 |
|---|---|
| **每轮自动配图** | 正文写完自动规划：配几张、插在哪、画什么，都在后台定，前台只管写故事 |
| **图片内联插入** | 图插在它描述的那段正文**后面**，按剧情分散，不堆在开头或结尾 |
| **跟正文版本绑定** | 回退或切换正文版本时，图自动隐藏；切回来又出现 |
| **本地 ComfyUI** | 连你本机的 ComfyUI（默认 `127.0.0.1:8188`），用你自己的模型和工作流 |
| **工作流库** | 导入 ComfyUI 的 API 格式 JSON，插件自动认出正负面 / 尺寸 / 步数 / 底模 / LoRA |
| **LoRA 管理** | 勾选启用、改权重、从已安装列表里选 |
| **画风预设** | 多套风格（画师串 + 专属负面词），一键切换 |
| **人物库** | 存角色的分块外貌（正/背面 × SFW/NSFW），生成时用宏调用 —— 同一角色每张图长得一样 |
| **生图世界书** | 决定「怎么把剧情翻译成提示词」，可导入、逐条编辑、逐条开关 |
| **设计角色** | 给一张参考图，让模型看图设计出可入库的角色 |
| **看图与重画** | 点开大图、左右翻页、滚轮缩放、按住拖动；右键改提示词重画，历史版本可对比 |
| **历史图库** | 看历史、批量删、右键改提示词重画 |

---

## 走的是官方接口，不是补丁

插件早期版本靠**给 Tavern 打补丁**才能把图塞进正文（自造渲染钩子 + 自建取图路由）。Tavern 一更新、补丁被冲掉，插件就瞎了：正文不显示图、按钮消失。

现在整条链路都走正门：

| 环节 | 用哪个官方接口 |
|---|---|
| 自动配图触发 | `tavern.onTurnSettled` —— 每轮结算后通知一次（不再由前端"渲染时猜"） |
| 图片挂进正文 | `tavern.attach` / `tavern.update` —— 按 `anchor` 锚定，与 `textVersion` 绑定 |
| 图片存储 | DSH `attachments.saveImage` —— 不再自建取图路由 |
| 手动「🎨 生图」按钮 | `tavernUi.registerMessageAction` |
| 正文 `image###` 标记 | `tavernUi.registerTextMarker` |
| 图片显示 / 尺寸 / 右键 | `tavernUi.registerMediaRenderer`（自定义媒体类型，显示方式归自己管） |
| 自动生图规则注入 | `tavern.promptSection` |

适配层在 `lib/tavern-bridge.js`，整个文件就是为这件事存在的。**插件自己的东西（ComfyUI 对接、工作流库、人物库、世界书、控制台）一个都没变。**

## 安装

**前置**：你已经在用 **DSH Desktop**，并且 **ComfyUI 能正常出图**。

### 方式一：从 GitHub 装（推荐）

```bash
cd ~/.dsh/profile-data/tavern/data/tools
git clone https://github.com/weixinlll/dsh-tavern-comfy.git
```

**然后完整重启 DSH Desktop**（关掉整个程序再打开，不是刷新页面）。

### 方式二：手动下载

下载本仓库，把文件夹放到：

```
Windows:      %USERPROFILE%\.dsh\profile-data\tavern\data\tools\dsh-tavern-comfy\
macOS/Linux:  ~/.dsh/profile-data/tavern/data/tools/dsh-tavern-comfy/
```

**完整重启 DSH Desktop。**

## 首次配置

重启后打开 **设置 → 本地生图**，五个标签页：**生图规划 / 人物库 / 历史图 / 世界书 / 画风**。

按顺序做四件事：

### 1. 填 ComfyUI 地址

**生图规划** 标签页最上面是「**生图后端**」：

```
API 根地址   [http://127.0.0.1:8188        ]
服务鉴权     [无需鉴权                    ▾]

[测试连接与鉴权]
```

点「**测试连接与鉴权**」，看到绿色的 `● 在线 0.38.2　RTX 4090　24GB　✓ 28ms` 就对了。

> ComfyUI 设了密码的话，在这里选 Bearer Token 或 Basic 并填上。

### 2. 导入一个工作流

**画风** 标签页 → **📥 导入工作流**

**必须用 ComfyUI 的「API 格式」导出**：

- ComfyUI 右上角菜单 → `Workflow → Export (API)`
- 或先在设置里打开 `Enable Dev mode Options`，菜单里会出现 `Save (API Format)`

导入后会告诉你识别到了什么：

```
✓ 已导入《my-flow》节点 12 个，识别到：
  正面 1 / 负面 1 / 尺寸 1 / 步数 1 / 底模 1 / LoRA 2
```

展开工作流，点「**✏️ 编辑 / LoRA**」能改提示词、尺寸、步数、底模和 LoRA。识别错了就在那里改。最后**设为默认**。

### 3. 选规划模型

**生图规划** 标签页往下，「**规划模型**」和「**看图模型**」都是下拉框：

```
规划模型  [渠道 ▾]  [模型名 ▾]        不选 = 跟随 Tavern 后台模型
看图模型  [渠道 ▾]  [模型名（👁）▾]   只列支持看图的
```

- **规划模型**：负责把剧情翻译成绘图提示词。**不选就跟随 Tavern 的后台模型。**
- **看图模型**：设计角色读参考图时用，**必须支持视觉**（带 👁 标记的）

> **想画 NSFW**：别用会拒绝的官方模型，选你自己的渠道模型。

### 4. 世界书（自带，开箱即用）

**世界书** 标签页默认有 **8 条「通用生图规则」**，全部启用。

> 首次运行时，插件会用随包附带的《世界书-通用生图规则》自动生成一份 `worldbook.json`。
> **之后永不覆盖** —— 你自己改过的条目会一直留着。

这些条目决定「**怎么把剧情翻译成提示词**」。默认那套已经调好，可以直接用；也可以导入别人的世界书、逐条开改。

## 怎么用

配好之后，**回聊天里正常对话就行**。

一轮正文写完，后台会自动：

1. 读一遍正文
2. 决定配几张图、插在哪几句后面、每张画什么
3. 翻译成英文提示词 → 交给 ComfyUI
4. 出图后按锚点插进正文

**想手动补一轮**：点消息下方那颗「**🎨 生图**」按钮，走的是同一条链路。

### 图能怎么摆弄

| 操作 | 效果 |
|---|---|
| **点一下图片** | 打开全屏查看器 |
| **右键 / 长按图片** | 改提示词、后台重写、重画 |
| **查看器两侧 ‹ ›** 或 **键盘 ← →** | 翻**整场对话里的插图** |
| **滚轮** | 缩放（0.2x ~ 8x） |
| **按住拖动** | 放大后平移 |
| **图片下方的「重画版本 ◀ 2 / 3 ▶」** | 翻**这张图自己的重画历史** |

标题栏会写清两件事，例如：

```
[褪白格子床上的交合]　第 3 / 18 张　（这张有 2 个重画版本）
```

### 重画

右键图片 → 改正向/反向提示词 → 点「**🎨 用这段重画**」。**同一条消息里换成新图**，旧版留在「重画版本」里可来回对比。

> 重画历史记在浏览器本地，**只有用查看器里的「🎨 用这段重画」画过的图才有版本行**。

## 两个开关，别搞混

插件里有两条**互不相同**的配图链路：

| 开关 | 在哪 | 默认 | 管什么 |
|---|---|---|---|
| **每轮自动规划配图（前台只写正文）** | 设置 → 本地生图 → **生图规划** 标签页 | **开** | 正文写完后**后台自动规划并插图**。前台模型完全不管图，多花一次规划调用 |
| **自动生图 / 生图数量** | **控制台**（右下角浮动按钮，或 `/plugins/dsh-tavern-comfy/console`） | 关 | 让**前台模型自己**在正文里写 `image###英文Tag###` 标记，浏览器侧再把它渲染成图 |

**推荐用第一个** —— 前台专心写故事，配图交给后台，画质和位置都更可控。

同一页往下还有两个值得调的：

- **一轮几张**（1~8，**建议 2~3**）：本地出图慢，设太多一轮要等很久
- **人物块**：`自动（画面露才带露出版本）` / `只带常规版本` / `全都带上` —— 控制人物库里 NSFW 分块什么时候进提示词

## 人物库（推荐建）

**人物库** 标签页里建角色。**每个角色分块存外貌**：

```
角色特征
五官（正面） / 五官（背面）
上半身 SFW / 上半身 SFW 背面
下半身 SFW / 下半身 SFW 背面
上半身 NSFW / 上半身 NSFW 背面
下半身 NSFW / 下半身 NSFW 背面
+ 常穿服装（可多套，标一套为「常穿」）
```

**为什么值得建**：填了名字 + 五官 + 体态的角色，会作为「**可用角色清单**」交给规划模型；正文里出现这个名字时，这些内容自动补齐 —— **这样同一个角色每张图长得都一样**，不会这一张黑发下一张白发。

生成时用宏调用：

```
${"name":"xiao yu", "angle":"from front", "upperBody":"sfw", "lowerBody":"sfw"}$
${"name":"湿透的灰色短打", "upperBody":"visible", "lowerBody":"visible"}$
```

- `angle`：`from front` / `from above` / `from below` / `from side` / `from behind`
- `upperBody` / `lowerBody`：`sfw`（有衣物）/ `nsfw`（裸露）/ `hidden`（不在画面里）

没建也能用 —— 模型会自己写外貌 Tag，只是稳定性差一点。

### 还可以让模型帮你建

**人物库 → 喂一张参考图 → 让模型设计**。模型会按「角色与服装设计规范」产出分块外貌，确认后写进人物库。

> ⚠️ 人物库有**防清空闸门**：保存时如果会把已有的角色清掉，插件会拒绝并提示，不会默默清库。

## 画风与工作流

**画风** 标签页管两件事：

**① 工作流** —— 导入的必须是 **API 格式**。导入后插件会自动识别：

| 识别项 | 靠什么 |
|---|---|
| 正 / 负面提示词 | 看**谁连到采样器**的 `positive` / `negative` |
| 尺寸 / 步数 / CFG | 采样器和 latent 节点的对应输入 |
| 底模 | CheckpointLoader / UNETLoader |
| LoRA | 所有 `LoraLoader` 节点 |
| 输出节点 | SaveImage / PreviewImage |

**多张工作流**：可以都导入，用「设为默认」切换。想锁住就勾「锁定」。

**LoRA**：展开工作流能看到所有 LoRA 节点，勾选启用（**停用 = 权重设 0，不删节点所以连线不会坏**）、改权重、从已安装列表里换。

**② 画风预设** —— 每套 = 画师串 + 专属负面词，还可以选「放在提示词最前还是最后」。多套之间一键切换。

## 世界书（进阶）

**世界书** 标签页 = **画图规则**。启用的条目会拼成一段规则，发给**规划模型**。

- **📥 导入世界书**：可以直接导 SillyTavern 的世界书 JSON；也可以把 JSON 或纯文本粘在下面（**纯文本按空行切成条目**）
- **逐条开关 + 改内容**：只有 `enabled` 是开关
- 条目里的 `{@setvar::...@}`、`{{...}}`、`<system_override>` 这类**给别的引擎看的语法会被自动剥掉**，不会污染规划模型

**输出契约**（想自己写规则的话，规划模型要按这个吐）：

```xml
<image>
<regex>从正文里原样复制的一句话</regex>
<title_styled>5~15 字中文标题</title_styled>
<Tag_think>这张画的画面概括</Tag_think>
<size>竖图</size>
<prompts>这里写提示词</prompts>
</image>
```

- **`<regex>`** 是**挂载位置** —— 插件拿它去正文里找，插在那句话之后。**必须逐字存在**，找不到就掉到末尾。
- **`<prompts>`** 是**提示词** —— 缺这个整块会被丢弃。

仓库里那份 `世界书-通用生图规则.json` / `.txt` 就是默认规则的原文（`.txt` 是纯文本版，方便复制粘贴给别人）。

## 常见问题

**Q：生成了但正文里没图**

按顺序查：

1. **生图规划** 里「每轮自动规划配图」有没有开
2. **规划模型** 选了吗（或让它跟随 Tavern 后台模型）
3. **画风** 里有没有「正在用这张」的工作流
4. 看设置页顶部的 ComfyUI 状态是不是绿的

**Q：图片掉到正文末尾了**

**规则里 `<regex>` 写的那句话在正文里找不着。** 去生成记录里看模型写的是什么，对照正文 —— 一般是它改写了原文（多字、少字、换了标点）。

**Q：规划跑完了但一张图都没有**

规划模型没按格式输出。**换个模型试试** —— 有些模型不认 XML 标签格式。用「规划模型」下拉换一个渠道模型。

**Q：图一直在「正在取回」**

出图文件落盘比作业标记完成要晚几十秒，插件会自动重试（1.5 秒一次，最多 20 次）。**等一会儿**；如果超过 30 秒还是取不到，点「重试」。

**Q：ComfyUI 连不上**

- ComfyUI 开着吗？（浏览器能打开 `http://127.0.0.1:8188` 吗）
- 地址填对了吗？（默认端口 8188）
- 设了密码的话，「服务鉴权」要选对并填上

**Q：出图很慢**

本地出图就这样。一张 768×1024 大概 20~60 秒（看显卡）。**建议「一轮几张」设 2~3**。

**Q：改了 `worldbook.json` 文件但插件没变**

插件缓存了世界书。**别直接改文件**，用「世界书」标签页改（它会自己刷新）。

**Q：改了代码没反应**

- **`client.js`（前端）**：刷新页面即可（会自动热重载）
- **`lib/`（宿主侧）**：必须**完整重启 DSH**（关掉整个程序），F5 不够

## 数据与隐私

**这些东西属于你，永远不会进公开仓库**（都在 `.gitignore` 里）：

```
config.json        你的 ComfyUI 地址、鉴权、工作流绑定
worldbook.json     你的生图规则（人物库 / 服装库 / 体位规则都在这里）
definitions.json   你的人物库、服装库
jobs-store.json    出图历史
plans-store.json   插图计划
backups/  cache/   备份与图片缓存
workflows/*.json   你自己的工作流
```

仓库里只有**代码**和**一份通用规则种子**。别人 clone 下去，拿到的是干净的空壳，第一次启动会自己生成默认世界书。
